# 🎮 MultiGames

Bienvenue sur **MultiGames**, une plateforme web qui regroupe plusieurs mini-jeux ludiques et éducatifs !

## 🚀 Aperçu

MultiGames propose une interface moderne et responsive pour accéder à différents jeux :

- **Calculaton** : Testez votre rapidité et vos compétences en calcul mental.
- **Démineur** : Retrouvez le classique jeu du démineur revisité.
- **TradGames** : Améliorez vos compétences en traduction avec des phrases à traduire.

De nouveaux jeux seront ajoutés régulièrement !

---

## 📂 Structure du projet

```
Multigames/
│
├── Calculaton/         # Jeu de calcul mental
├── Projet Démineur/    # Jeu du démineur
├── TradGames/          # Jeu de traduction
```

---

## 🕹️ Accès aux jeux

Depuis la page d'accueil (`index.php`), choisissez le jeu qui vous intéresse :

- **Calculaton** : [Calculaton/index.php](./Calculaton/index.php)
- **Démineur** : [Démineur/index.html](./Projet%20D%C3%A9mineur/Version%202/index.html)
- **TradGames** : [TradGames/index.php](./TradGames/index.php)

Chaque jeu possède ses propres règles et son interface dédiée.

---

## 🛠️ Installation & utilisation

1. **Téléchargez ou clonez** ce dépôt sur votre machine :
	```
	git clone <lien-du-repo>
	```
2. Placez le dossier sur un serveur local (ex : XAMPP, WAMP, MAMP) pour profiter des fichiers PHP.
3. Ouvrez `index.php` dans votre navigateur pour accéder à la plateforme.

> **Note :** Certaines fonctionnalités (sons, images) nécessitent que le site soit servi depuis un serveur local ou distant.

---

## ✨ Personnalisation

- Ajoutez vos propres images dans le dossier `img/` pour illustrer les jeux.
- Modifiez ou ajoutez de nouveaux jeux en créant de nouveaux dossiers et en adaptant la page d'accueil.
